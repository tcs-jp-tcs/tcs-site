# TCS Portfolio Site

TCS（個人事業主）のポートフォリオサイト。

## 収録プロダクト
- F-LABO — モータースポーツ専門メディア / https://f-labo.vercel.app
- Carely — 血圧管理PWA / https://carely-bp.vercel.app
- Shifly — 病院向けシフト管理デスクトップアプリ（Electron / Windows）
- Archly — 案件管理Webアプリ / https://archly-nine.vercel.app

## 構成
- 単一のHTMLファイル（index.html）で完結
- 外部依存は Google Fonts のみ
- ロゴ画像は data URI として埋め込み
- Archlyのデモ画面は base64 で埋め込み、ボタン押下時に iframe で表示

## Archlyデモについて
画面イメージであり、実際に動作するアプリケーションではありません。
表示されているデータは全て架空のものです。
