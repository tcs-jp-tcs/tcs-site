血圧を、撮るだけ・話すだけで記録するWebアプリ。

血圧計をカメラで撮影するとAIが数値を読み取って自動入力するPWA。インストール不要でスマホのホーム画面に追加でき、データは端末内に保存。提携医療機関で実証中です。

  • CAM
    撮る → AIが数値を自動入力

    血圧計の画面をカメラで撮影すると、Groq Vision APIが数値（上・下・脈拍）を読み取ってフォームへ自動入力。手打ち不要。

  • VOI
    話す → 音声で入力

    「135、85、72」と話すだけでも記録できる。撮影が難しい場面の代替入力。

  • GRA
    貯める → グラフで見える

    朝・夕の血圧の変化がひと目でわかるグラフ表示。継続記録を支援する。

  • LOC
    守る → データは端末内に保存

    記録はスマホ側にローカル保存。登録不要・インストール不要で始められる。

TECHNICAL DOSSIER ／ 開発と運用

毎月のシフト作成を、ボタンひとつで自動作成。

複雑な勤務ルールや個人の希望を反映しながら月間シフトを自動で組み立てるデスクトップアプリ。現場の実務に合わせて開発し、医療機関で導入・運用中。バージョンを重ねながら継続的に改善しています。

  • AUTO
    自動作成 → 勤務ルール + 希望を反映

    ルールと希望をもとに月間シフトを自動で組み立て。「この人の・この曜日を・こうする」を画面で細かく設定できる。

  • CHK
    チェック → 守るべき条件を自動確認

    システムが自動でチェックする勤務条件を画面で確認できる。ルール違反を作成段階で防ぐ。

  • XLSX
    入出力 → Excelと行き来

    作成したシフト表をExcelへ書き出してそのまま印刷。使い慣れた勤務表の希望をそのまま取り込むこともできる。

  • SAVE
    保存 → ローカルに安全保存

    保存先を指定でき、3世代バックアップと破損時の自動復旧に対応。データは端末内で完結。

  • CRUD
    案件管理 → ダッシュボードで完結

    作成・進捗確認・アーカイブまで一画面で。依頼済 → 確認中 → 作成中 → 確認待ち → 完了の5段階ステータス。

  • CHAT
    やりとり → 案件ごとにスレッド化

    案件単位でチャットが分かれ、既読も同期。メール・チャット・フォルダを行き来する非効率を減らす。

  • FILE
    共有 → 大容量ファイルも案件から直接

    ブラウザから資料や動画を案件ページへ直接アップロード。OneDrive連携にも対応。

  • RLS
    権限 → DB側で制御

    行レベルセキュリティをPLpgSQLでフェーズ分けして実装。メッセージ・ファイル・通知ごとにアクセス範囲を制御。
